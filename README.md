# 🐾 Poket Vet & Pet Shop - Full-Stack Web Application

A professional, full-stack pet care management and e-commerce platform built for a computer science portfolio. The application features a dynamic responsive single-page interface, a Node.js/Express REST API backend, and persistent MySQL database storage.

---

## 🚀 Key Features

* **Dynamic SPA Navigation**: Seamlessly switch between Home, Shop Catalog, Pet Services (Breeding & Shelter), Veterinary Care, and About Us views using vanilla JavaScript DOM rendering.
* **MySQL Inventory Management**: Real-time product tracking based on SKU, stock quantities, pricing, and category filters.
* **Secure User Authentication**: Complete registration and login workflow tied directly to a MySQL `users` database table with persistent session state management via `localStorage`.
* **Interactive Shopping Cart**: Add products or book services, manage quantities, calculate totals in Indian Rupees (₹), and execute authentication-gated checkout workflows.
* **Admin Inventory Control**: Dedicated modal interface allowing administrators to add new products directly into the MySQL database.

---

## 🛠️ Technology Stack

* **Frontend**: HTML5, CSS3, JavaScript (ES6+), FontAwesome Icons, Unsplash Imagery.
* **Backend**: Node.js, Express.js, RESTful routing, CORS middleware.
* **Database**: MySQL (Relational database management system via `mysql2` pool connections).
